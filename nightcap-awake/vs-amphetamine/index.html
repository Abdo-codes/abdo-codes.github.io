Nightcap Awake vs Amphetamine, KeepingYouAwake, and caffeinate

Verdict: Pick Amphetamine if you need closed-lid MacBook keep-awake, Wi-Fi/USB triggers, or schedules, and pick KeepingYouAwake if you prefer a manual timed toggle. Pick Nightcap Awake if you want a free, MIT open-source, sandboxed Mac App Store menu bar app with zero network access that keeps your Mac awake only while chosen apps like Xcode, Codex, Claude Code, or Ghostty are running.

Tool-by-tool breakdown

When each tool is the right pick

1. Nightcap Awake

Verdict: Built specifically to keep your Mac awake while chosen developer apps run, then sleep normally when they quit.

  • Best for: Developers running Xcode builds, Claude Code, Codex, Ghostty, or long exports who want zero manual toggling and inspectable MIT source code.
  • Strengths: Sandboxed Mac App Store build + Homebrew cask, zero network entitlements, zero analytics, allows display to turn off while CPU work finishes.
  • Trade-offs: Requires macOS 14+, no closed-lid clamshell override, no schedule or Wi-Fi triggers.
  • Price: Free (MIT).

2. Amphetamine

Verdict: The most feature-complete keep-awake utility on macOS with triggers, schedules, and closed-lid sessions.

  • Best for: Power users who want sessions triggered by Wi-Fi SSID, battery threshold, connected displays, or closed-lid MacBook use.
  • Strengths: Free on Mac App Store, mature trigger engine, keeps screen awake when needed, optional Enhancer helper for closed-lid mode.
  • Trade-offs: Closed source; heavier preferences UI if you only ever wanted app-based wake rules.
  • Price: Free.

3. KeepingYouAwake

Verdict: A trusted, open-source MIT menu-bar wrapper around macOS caffeinate for quick timed toggles.

  • Best for: People who want a classic one-click coffee cup icon ("stay awake for 1 hour / 5 hours / indefinitely") with open-source code.
  • Strengths: MIT licensed, widely audited on GitHub (7,058 stars), supports older macOS versions, available via Homebrew.
  • Trade-offs: No automatic watched-app list; not distributed on the Mac App Store; easy to leave toggled on overnight.
  • Price: Free (MIT).

4. Apple caffeinate (CLI)

Verdict: Built directly into macOS with zero installation required for single terminal commands and shell scripts.

  • Best for: One-off commands (caffeinate -i ./deploy.sh) or CI/automation scripts where no GUI app belongs.
  • Strengths: Zero install, native macOS assertion flags (-i idle, -d display, -t seconds, -w wait for PID).
  • Trade-offs: Ends when the Terminal tab closes; requires remembering to wrap every build or agent launch manually.
  • Price: Built into macOS.
Quick setup

Switch from Amphetamine or caffeinate in 2 minutes

  1. Install Nightcap Awake: grab it free on the Mac App Store or run brew install --cask Abdo-codes/tap/nightcap.
  2. Add your watched apps: click the cup icon in the menu bar and pick Xcode, Ghostty, Terminal, Codex, or any app that runs long jobs.
  3. Turn on Launch at Login and let Nightcap run silently in the background. When you clean Xcode DerivedData or run parallel agents across Git worktrees, your Mac stays awake until the app quits, then sleeps normally.
  4. Disable overlapping holds: quit Amphetamine or remove custom caffeinate aliases so only one app manages sleep assertions.
Questions

Comparison FAQ

Is Nightcap Awake a full replacement for Amphetamine?
No. If you need closed-lid MacBook keep-awake, Wi-Fi/power-adapter triggers, or timed schedules, stay with Amphetamine. Nightcap Awake is for users who want one focused, MIT open-source rule: stay awake while chosen apps run, sleep when they quit.
How does Nightcap Awake compare to KeepingYouAwake?
Both are free and MIT licensed. KeepingYouAwake is a manual/timed toggle wrapper around caffeinate. Nightcap Awake watches running apps automatically, lets your display turn off normally, and ships sandboxed on the Mac App Store as well as Homebrew.
Why not just run caffeinate in Terminal?
caffeinate -i <command> is great inside a shell script, but you have to remember to invoke it before every GUI Xcode build or agent session. Nightcap Awake holds and releases the macOS power assertion automatically.
Does Nightcap Awake keep my MacBook awake with the lid closed?
No. Because Nightcap Awake runs inside the macOS App Sandbox with standard idle-sleep assertions, closing the lid on battery still puts your MacBook to sleep. Use Amphetamine if you need closed-display mode.
