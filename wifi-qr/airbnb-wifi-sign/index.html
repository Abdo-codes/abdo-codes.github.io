How to make an Airbnb WiFi sign with a QR code

Guests ask for the WiFi password first. A good sign answers before they ask: the network name, the password and a QR code that they scan with the phone camera. This guide tells you what to put on the sign, where to put it and how to make one in a few minutes.

What to put on it

What an Airbnb WiFi sign needs.

Keep the sign short. Guests read it from a table or a wall, often with a phone already in one hand.

Net

The network name

Write it exactly as the phone shows it. Network names are case-sensitive, so "BeachHouse" and "beachhouse" are two different names.

Key

The password

Use a clear font and enough space. In many fonts, O and 0, or l, I and 1, look the same. Every character must stay readable, also on a long password.

QR

A Wi-Fi QR code

Guests point the camera at the code and tap Join. There is no typing and no wrong letter. Keep the name and password in text too, for laptops and TVs.

Help

One line of help

"Open the camera and point it at the code." If guests may need to restart the router, say where it is.

Title

A welcome title

"Welcome to the Lake Cabin" makes the card part of the home, and tells guests that the card is for them.

Host

How to get help

Add a short footer, for example "WiFi problems? Message us in the Airbnb app." Guests then know what to do first.

Where to put it

Put the sign where guests look first.

Most guests look for the WiFi in the first ten minutes. Put the sign on that path, and put a second copy where they use the internet most.

The entry table or kitchen counter This is the first flat place where guests put down bags, keys and phones.
The fridge, or a frame on the wall A 4 x 6 or 5 x 7 card fits a small frame, a stand or a magnet sleeve.
Near the TV or the desk Guests sign in to streaming apps here, or work on a laptop that cannot scan a code.
The welcome book and the listing Put a full page in the house manual. Also add the network name and password to the WiFi details in your Airbnb arrival guide, so guests have them before they arrive.
Size and printing

Pick a size, then print it to scan.

A WiFi card for Airbnb does not need to be large. It needs a QR code that the camera can read from an arm's length away.

4 x 6 in A photo-size card for a bedside table, a shelf or a small frame.
5 x 7 in A frame on the entry table or the wall. Easy to read from a few steps away.
A4 or US Letter A page for the welcome book, or a wall in a shared kitchen or lobby.
Print tips Print at 100%, not "fit to page". Keep the QR code at least 3 cm (1.2 in) wide. Glossy plastic can reflect light, so use a matte sleeve.
How guests scan

Guests join with the camera. No app needed.

A Wi-Fi QR code holds the network name, the security type and the password. The phone reads them and joins the network.

iPhone and iPad Open the Camera app, point it at the code and tap the Join banner.
Android Open the camera or Google Lens, point it at the code and tap Connect. Most new Android phones can do this.
Laptops, TVs and game consoles These cannot scan the code. Guests type the name and password from the sign, so keep both in large text.
Safety

Use a guest network, and keep the sign inside.

A WiFi sign shows the password to every guest. Set up the network for that, and the sign is safe to leave out.

Guest network Many routers can make a separate guest network. Guests get the internet, but not your cameras, smart locks or own devices.
New password Change the password when you need to, for example once a year. The old QR code then stops working, so print a new sign.
Long password A long random password is safer. Guests scan it, so the length does not matter to them.
Inside only Put the sign where only guests see it. Do not put it in a window or at the street door.

FAQ

Airbnb WiFi sign questions.

What should an Airbnb WiFi sign include?

The network name, the password, a Wi-Fi QR code and one line that tells guests to scan the code with the phone camera. A welcome title and a short footer are optional.

Do guests need an app to scan a WiFi QR code?

No. The iPhone Camera app and most Android cameras read Wi-Fi QR codes. Guests point the camera at the code and tap Join or Connect.

What size should an Airbnb WiFi card be?

A 4 x 6 in or 5 x 7 in card fits a frame on a table, a shelf or a wall. Use A4 or US Letter for a page in the welcome book or house manual.

Is it safe to put the WiFi password on a sign?

Yes, if you use a guest network and keep the sign inside the home, where only guests see it. Change the password when you need to, and print a new sign.

Does the QR code still work after I change the password?

No. The QR code holds the password. After each change, make a new code and print a new sign.

Is an app better than a Canva or Etsy WiFi sign template?

With a template, you make the QR code in a different tool and paste it in. Wi-Fi QR makes the code from your network details and puts it on the sign, so the code and the text always agree.

Can I make an Airbnb WiFi sign for free?

Yes. Wi-Fi QR is free on iPhone and iPad, with no ads, no account and no in-app purchases.
